# China Holiday Calendar - 中国节假日日历

用于补充 **Apple 日历（Calendar）中“ 中国大陆节假日 ”订阅日历缺失的节日**的补丁订阅源。

本仓库提供 `.ics`（iCalendar）文件，可作为“订阅日历”添加到 iPhone/iPad/Mac，在不影响原订阅的前提下补齐缺失条目。

## 原则
- 事件 **只保留节日名称**（`SUMMARY`），不包含额外描述/链接。

## 如何使用
### iPhone / iPad
日历 App → 底部“日历” → 添加日历 → 添加订阅日历 → 粘贴订阅链接 → 查找 → 保存

### Mac
日历 App → 文件 → 新建日历订阅 → 粘贴订阅链接 → 订阅 → 保存

> 订阅日历为只读；不需要时可取消订阅。
